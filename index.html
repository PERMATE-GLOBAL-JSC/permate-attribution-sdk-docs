Permate Attribution SDK for Android

The Permate Attribution SDK connects Android app installs, opens, and deep-link interactions with Permate campaign attribution.

SDK namePermate Attribution SDK for Android
Maven IDcom.permate:permate-attribution
Current stable version3.2.0

Maven repository

The SDK is distributed from Permate's public, immutable Maven repository:

https://sdk.pmcdn1.com/maven/releases/

The repository root intentionally has no browsable directory index. Gradle and Google tooling resolve the anonymous POM, module metadata, AAR, and release evidence through their standard versioned Maven paths.

Install with Gradle

Add the repository to dependency resolution:

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://sdk.pmcdn1.com/maven/releases/") }
    }
}

Add the stable SDK dependency:

// app/build.gradle.kts
dependencies {
    implementation("com.permate:permate-attribution:3.2.0")
}

Initialize the SDK

A Permate application key is required. Keep production and staging keys outside source control.

PermateAttribution.configure(
    context = this,
    appKey = BuildConfig.PERMATE_APP_KEY,
    options = AttributionOptions(
        environment = if (BuildConfig.DEBUG) Environment.STAGING else Environment.PRODUCTION,
        logLevel = if (BuildConfig.DEBUG) LogLevel.VERBOSE else LogLevel.ERROR,
    ),
)
PermateAttribution.start()

The Android library supports API 23 and later. A missing or blank app key results in a safe no-op rather than an application crash.

Published release and verification

Stable versions are create-only: an existing Maven path is never overwritten. Version 3.2.0 was independently rebuilt, resolved by a cold-cache consumer, and checked against its signed public release evidence.

Distribution policy

  • The canonical Maven ID is com.permate:permate-attribution.
  • Stable releases use immutable versioned paths under the repository URL above.
  • The SDK does not require Maven repository authentication.
  • Consumers should use exact versions; preview repositories and mutable aliases are not part of the stable distribution contract.
